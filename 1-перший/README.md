# Q-team · Новорічний корпоратив 2027 · нова версія

Статичний сайт без збірки: `index.html`, `style.css`, `main.js`, `tree-data.js`, `assets/`.
Перші три блоки за Figma (сторінка «desktop 2»):

1. **Hero · ялинка з полароїдів** (вузол 470:13068). Полароїди злітаються знизу вгору, падає зірка, домальовуються стрілки. При наведенні фото вилітає вперед і збільшується, як на попередній версії сайту. Кнопка «Залишити заявку» веде на `#zayavka` (сюди стане форма).
2. **Поштові марки** (470:13295). Коли блок з'являється на екрані, марки по черзі «штампуються» на сторінку. При наведенні фото-марки піднімаються й збільшуються.
3. **«А може, цього року нічого не проводити?»** (530:52). Коли заголовок доходить до верху екрана або блок повністю видно, кулька похитується, падає й розбивається.

Кожен блок зверстаний на 1920 px і пропорційно масштабується під ширину вікна. Мобільних макетів поки немає.

